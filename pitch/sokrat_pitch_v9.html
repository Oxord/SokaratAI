11 Технические сложности

Что было нелегко собрать за 8 часов

StateGraph с условными переходами

interrupt_before + петли collect_context и analyze_answer → interview. Граф приостанавливается до ввода.

Корректно прокинуть state через все ветки и не потерять контекст.

Структурированный вывод LLM

with_structured_output(AnswerEvaluation, json_mode) + Pydantic-валидация и автоматический retry на невалидный JSON.

Гарантировать валидный JSON от LLM, не уронив сценарий.

Мульти-намеренческий анализатор

LLM классифицирует ответ по 5 intent: answer / clarification / dont_know / skip / meta. На «не знаю» — даём подумать, на повтор — фиксируем 0.

Промпт переписывался дважды, вырос с 31 до 107 строк.

Фоновое самообучение банка

После сессии asyncio-задача генерирует 2 новых вопроса и атомарно дописывает в банк: .tmp + fsync + os.replace под threading.Lock.

Запись без гонок при параллельных сессиях.

Fallback-цепочка надёжности

На каждом узле — fallback из банка вопросов и жёсткий fallback. Пользователь не видит падение API.

Каскадная обработка ошибок без потери UX.
Fallback-цепочка: ошибка LLM → банк → жёсткий fallback. Пользователь никогда не видит падение.
